# Words come first.

Open a Markdown document to read it. Use the menu in the top left to switch to **Writing** or **Typewriter**.

> **Welcome to Carta.** Drop a `.md` file here or press **⌘O** to open one from your Mac.

## A quiet place to read

Notes, documentation, ideas you’re still sorting out. Carta gives your words room with clear typography and an outline that follows the document’s structure.

- **Find your place.** Use the outline on the left to jump to a section.
- **Read in your preferred theme.** Open the **Aa** menu and choose Light, Dark, or Paper.
- **Keep up with changes.** If you edit the file in another editor, the preview updates automatically.

## A place for everything

Markdown comes to life with **bold**, *italic*, ~~strikethrough~~, [links](https://commonmark.org), and `inline code`.

### The little things

- [x] Tables and task lists
- [x] Images and links relative to the document
- [x] Preview and source views
- [ ] Your next idea

### Room for code

```swift
let thought = "Ideas start with a line."
print(thought)
```

## Keyboard shortcuts

| Action | Shortcut |
| :--- | :--- |
| Open a document | ⌘O |
| Start a new document | ⌘N |
| Save the document | ⌘S |
| Find in the document | ⌘F |
| View Markdown source | ⇧⌘U |
| Increase or decrease text size | ⌘+ / ⌘− |
| Print or save as PDF | ⌘P |

---

Your files stay where you put them. Carta writes your edits to disk when you save.
