# Le parole, al centro.

Apri un documento Markdown per leggerlo. Dal menu in alto a sinistra puoi scegliere **Scrittura normale** o **Macchina da scrivere**.

> **Benvenuto in Carta.** Trascina qui un file `.md` oppure premi **⌘O** per aprirlo dal tuo Mac.

## Una lettura senza distrazioni

Appunti, documentazione, idee ancora da mettere in ordine. Carta dà spazio alle parole con una tipografia curata e un indice che segue la struttura del documento.

- **Ritrova il filo.** Usa l’indice a sinistra per saltare a una sezione.
- **Scegli la tua luce.** Dal menu **Aa**, passa al tema chiaro, scuro o carta.
- **Resta aggiornato.** Se modifichi il file nel tuo editor, l’anteprima si aggiorna da sola.

## Tutto al suo posto

Il Markdown prende forma: **grassetto**, *corsivo*, ~~testo barrato~~, [collegamenti](https://commonmark.org) e `codice in linea`.

### Anche le piccole cose

- [x] Tabelle e liste di attività
- [x] Immagini e collegamenti relativi al documento
- [x] Anteprima e vista del sorgente
- [ ] La tua prossima idea

### Spazio al codice

```swift
let pensiero = "Le idee iniziano con una riga."
print(pensiero)
```

## I gesti che servono

| Azione | Scorciatoia |
| :--- | :--- |
| Aprire un documento | ⌘O |
| Iniziare a scrivere un nuovo documento | ⌘N |
| Aprire il menu contestuale Markdown in scrittura | Premi e rilascia ⌥ Option da solo |
| Salvare il documento | ⌘S |
| Cercare nel testo | ⌘F |
| Vedere il sorgente | ⇧⌘U |
| Ingrandire / ridurre il testo | ⌘+ / ⌘− |
| Stampare o salvare in PDF | ⌘P |

I file restano dove li hai messi. Le modifiche vengono scritte su disco quando salvi.
