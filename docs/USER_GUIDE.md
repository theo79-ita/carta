# Using Carta

## Open and save a document

Open a Markdown file with **⌘O**, drop it into the window, or choose **Open With → Carta** in Finder. Use **⌘N** to begin a new document in the last writing mode you used. Carta registers as an alternate editor for Markdown documents. You can also open plain text from within the app.

Choose **Reading** to preview the current text, even before saving. **⌘S** writes changes to the current file. If another program changes the file on disk, use **⇧⌘S** to save your draft under another name. Save As writes UTF-8. When saving to the original file, Carta preserves supported encodings where the text can be represented.

## Work with Markdown

Tap and release **Option** on its own to open the insertion menu. Use **↑** and **↓** to move, **→** to enter a submenu, **←** to return, **Return** to insert and **Esc** to dismiss. The same commands are available through **Insert Markdown** in the context menu.

Select some text to wrap it in formatting, select several lines to turn them into a list, or select tab-separated cells to create a table. A template inserted at an empty caret selects its first editable field. Use **⌘Z** to undo it. Entries under **Other Editors · Source Only** insert syntax intended for other Markdown readers.

## Set up the typewriter

Choose **Typewriter**. The ruler tracks the caret while the page stays still as you type. On Return the indicator moves back to the left margin and the ruler follows the next line. The paper advances a few lines once the active line reaches about two thirds of the writing area. You can also scroll manually.

The A4 page represents 210 × 297 mm using the physical size reported by the display. If the scale looks wrong, click **A4** in the lower-right corner. Measure the distance between the two marks with a ruler and enter it in millimetres, or enter the display diagonal in inches. Carta remembers the correction for each display. Additional sheets continue the same text without inserting page breaks into the Markdown file.

The lock releases the right margin. The speaker toggles all typewriter sounds. The glass controls respond to the macOS Reduce Transparency setting.

## Read and navigate

Click a heading in the outline to jump to its section. The remaining-time estimate stays below the document and updates as you scroll in either direction. A document that fits in one window keeps its full estimate. The reader supports tables, task lists, quotations and fenced code blocks. Wide tables scroll horizontally. Use the copy button on a code block to copy its contents.

Choose the system, light, dark or paper theme, and set text size from 13 to 24 px. In reading mode, **⌘F** searches the document, **⇧⌘U** shows its source and **⌘P** opens the macOS print dialog, where you can choose **Save as PDF**.

Relative image paths resolve inside the document's folder, including its subfolders. Links to supported local documents open in Carta. Clicking a web or email link opens the corresponding system application. Remote image URLs can be fetched as you read.
